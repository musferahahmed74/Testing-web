##  What to Include With Your Challenge 

Before submitting your challenge, make sure you've included everything the TMON team needs to review, test, and eventually add it to the platform.

### 1. Challenge Files

Include all the files or resources a player needs to solve the challenge i.e.

* Logs
* PCAP files
* Source code
* Binaries
* Web files
* Configuration files
* Docker files
* Other required resources

Make sure the files you submit are complete and actually work as intended.

### 2. Challenge Description

Give the players a scenario and objective to acheive.
If your challenge has any hints, mention them here as well.

### 3. Challenge Metadata

Include the basic information about your challenge:

* **Challenge name**
* **Category**
* **Technique / MITRE ATT&CK technique**
* **Difficulty level**
* **Estimated time for giving hint**, if applicable
* **Required tools or environment**
* **Operating system this challenge is based upon: Windows/Linux/Mac/Andrioid**

This helps us organize your challenge and helps players understand what they're getting into.

### 4. Challenge Write-up / Solution

A walkthrough which explains what are the steps, that needed to be taken in order to solve the challnge.
Make sure to add the flag at the end as well.

### 5. Setup & Deployment Instructions

If you challenge requires any special services, ports or dependencies please mention them.

The TMON team should be able to follow your instructions and get the challenge running without having to guess what you intended.

### 6. Author Information

Finally, let us know who created the challenge.

Please include:

* Your GitHub username
* Your name or preferred contributor name
* Your e-mail
